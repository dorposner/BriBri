# Bribri Translator

The first comprehensive Bribri language translator online, designed to help preserve and study the Bribri language. This progressive web app (PWA) offers robust search, categorization, and a smooth mobile-first experience.

## Features

- **Multi-Language Support**: Translate between Bribri, English, Spanish (Español), and Hebrew (עברית).
- **Fuzzy Search & Auto-Suggestions**: Powered by `fuse.js`, making it easy to find words even with slight misspellings or missing diacritics.
- **Extensive Dictionary**: Includes the entire Haakon Krohn database, mythological terms, and frequent conversational expressions from lenguabribri.com.
- **Mobile-First UX**: A clean, app-like interface featuring a bottom navigation bar for seamless switching between views.
- **Browse by Category**: Explore vocabulary grouped by topics with smooth scrolling to categories.
- **A-Z Alphabetical Index**: Browse the dictionary alphabetically in any of the four supported languages.
- **Pronunciation Guide**: Learn about Bribri vowels, tones (high, low/falling, nasal), and specific consonants like the glottal stop.
- **Progressive Web App (PWA)**: Installable on mobile and desktop devices with offline capabilities through a service worker.

## Architecture

- Built with HTML, CSS, and vanilla JavaScript.
- Client-side search and rendering for maximum speed and offline support.
- `fuse.js` for advanced fuzzy searching capabilities.
